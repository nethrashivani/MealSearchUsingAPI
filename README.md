# MealSearchUsingAPI

## 🍽️ Meal Recipe Search App (with API)

### 📌 Overview

This is a **Meal Recipe Search Application** built using HTML, Tailwind CSS, and JavaScript.
It uses a public **recipe API** to fetch food dishes based on user search input.

Users can:

* 🔍 Search for recipes by ingredient or dish name
* 📄 View recipe instructions
* ▶️ Watch a YouTube video tutorial for the recipe
* 🍴 Explore multiple food ideas instantly

This project helped me practice **APIs, fetch(), async/await, and dynamic DOM updates**.

---

### ✨ Features

* 🔎 Search meals by name or ingredients
* 📛 Displays meal name + thumbnail image
* 🍽️ “View Recipe” button to see full cooking instructions
* 🎥 “Watch Video” button redirects to recipe YouTube tutorial
* ⚡ Dynamic content rendering
* 📱 Responsive UI using Tailwind CSS
